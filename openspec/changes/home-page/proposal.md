## Why

Scheme Sathi needs a landing page that immediately communicates its value proposition — helping SC beneficiaries find the right government scheme. The home page is the entry point for the entire user journey and must establish trust, clarity, and accessibility for users with limited digital literacy.

## What Changes

- Hero section with primary CTA "Find My Scheme" and secondary CTAs
- "How It Works" 5-step visual flow
- Feature showcase sections (Smart Matching, Financial Calculator, Partner Locator, Voice Assistant, DigiLocker)
- Popular/featured schemes section
- Financial literacy section
- FAQ section
- Trust/official sources attribution
- Responsive navigation with mobile menu
- Footer with links and accessibility controls
- Language selector in header

## Capabilities

### New Capabilities
- `landing-page`: Home page layout, hero, navigation, footer, responsive design
- `how-it-works`: 5-step visual flow explaining the product journey
- `feature-showcase`: Display cards for core product features on home page

### Modified Capabilities

(none — first change)
